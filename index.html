🎯 HackScout

An open agentic web demo site: publishes a portable multi-agent network (Neuro SAN HOCON/JSON), runs it entirely in your browser via the nsDeploy reference runtime, and supports Bring-Your-Own-Key inference. Built for the Open Agentic Web Challenge.

agent-manifest.jsonhack_scout.network.jsonlinks.jsonCORS open

Published artifacts: a 4-agent network — hack_scout_gm (front), hackathon_finder, bounty_evaluator, submission_coach. Peers can fetch and run this network in their own browser after consent.

Peer linking: point your runtime at /agents/agent-manifest.json or the network URL /agents/hack_scout to load this network as a peer. Default inference runs on this site's published mock router; supply your own OpenAI-compatible key for real responses (stored only in your browser).
